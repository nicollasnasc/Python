Python — Estudos, Exercícios e Projetos

Este repositório reúne meus estudos contínuos em Python, organizados de forma progressiva.
O conteúdo parte de exercícios básicos de lógica e avança gradualmente para códigos mais estruturados, com foco em clareza, funcionamento correto e boas práticas.

Mais do que um conjunto de arquivos, este repositório funciona como um registro técnico de aprendizado e evolução.

Objetivo

O propósito deste repositório é:

Consolidar fundamentos da linguagem Python

Desenvolver raciocínio lógico aplicado

Praticar escrita de código legível e organizado

Evoluir de exercícios simples para projetos mais completos

Manter um histórico público e transparente de aprendizado

A progressão do conteúdo é intencional e reflete o estágio de estudo em cada momento.

Execução dos Códigos

Não há dependências externas nem configuração avançada.

Verifique se o Python está instalado:

python --version


Navegue até a pasta desejada

Execute o arquivo:

python nome_do_arquivo.py
